# ishur.io · brand assets

Generated from the site's own logo and the Invitation palette
(pine #1F3329, gold #A8853C, paper #F8F4EA).

## Phone wallpapers

| File | Use |
|---|---|
| `wallpaper-lock-iphone-1290x2796.png` | lock screen, iPhone |
| `wallpaper-home-iphone-1290x2796.png` | home screen, iPhone |
| `wallpaper-lock-android-1080x2400.png` | lock screen, Android |
| `wallpaper-home-android-1080x2400.png` | home screen, Android |

Lock carries the mark, rule and wordmark, sitting below where the clock lands.
Home is ground and texture only, with the wordmark parked in the clear band
under the status bar so the dock never covers it and icon labels stay readable.

The faint squares are the logo's own pixel dissolve, thinned out through the
middle of the screen so app icons keep a calm background.

## WhatsApp profile photo

640px is enough for WhatsApp, these are 1000px so they survive re-compression.
WhatsApp crops to a circle; the mark sits well inside it.

| File | Look |
|---|---|
| `whatsapp-gold-1000.png` | pine ground, gold check. Matches the wallpapers. |
| `whatsapp-green-1000.png` | pine ground, brand green check. |
| `whatsapp-ivory-1000.png` | ivory ground, the site logo as is. Reads brightest in a chat list. |

In a chat list this renders near 48px. `ivory` holds up best at that size
because of the light ground; `gold` looks the most premium at profile size.
