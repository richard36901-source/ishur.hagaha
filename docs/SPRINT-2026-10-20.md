## אישורים שנדרשים מריצ׳רד (פעם אחת)

1. **מורנינג** — להיכנס ל-app.morning.co.il → הגדרות → API → לייצר מפתח חדש (אם הישן בוטל), ולהריץ `npx wrangler secret put MORNING_ID` / `MORNING_SECRET`.
2. **מספר שני לשיר** — לאשר רכישת מספר ישראלי ב-Telnyx (~$1/חודש) או לתת SIM. (חסום עד אימות העסק: מכסת 2 מספרים.)
3. **הודעת המשך לאורחים** — לאשר נוסח: "תודה! כמה תגיעו בסך הכל? (אפשר לענות רק מספר)".
4. **דיילות** — לאשר שהלינקים ב-Grow: 1 דיילת ₪1,790, 2 דיילות ₪1,990 (לעדכן/ליצור ב-Grow — אני מכין, אתה מאשר).
5. **פריסה** — כל שלב נפרס בנפרד; אני מודיע, אתה מריץ `deploy`.
