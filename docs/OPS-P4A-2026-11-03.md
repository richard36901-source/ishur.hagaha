Branch `p4-inbox` from `integ-2026-11-02` (75c3e34). Not deployed.

## Endpoints (worker/ops-inbox.js, routed in worker/ops.js; all admin, read-only)
- `GET /api/ops/messages?day=YYYY-MM-DD&tab=all|failed|replies&cursor=<ts>&limit=` : one row per message. Audit `wa_out` rows joined to `wa_status` by wamid (the row keeps the highest status: failed > read > delivered > sent, plus the full history), the guest reply = the first `wa_in` from that phone within 24 h of the send (and before that phone's next send). Fields: id/wamid, number label (שיר #1/#2/נועה/SMS), to + to_name + to_role, event, type (wave/daybefore/eventday/table/thanks/gift/subevent/reply/manual/client), template, text, status, error_code, reply, reason, statuses. `replies` tab = inbound rows with `in_reply_to`.
- `GET /api/ops/inbox?channel=` : the /api/inbox conversation list (same data, `handleInbox` now wraps a shared `inboxData()`) + role badge (client from the sheet, lead from `lead:<phone>`, guest), event, unread (= the last message is theirs), 24 h window, takeover. Unread first.
- `GET /api/ops/thread?phone=` : bubbles, `window{open, closes_at}`, `channel` (client/guests), `takeover{human, ai}`, the template list (the same 5 inbox.html offered).
- `GET /api/ops/control` : paused, Noa AI state (KV `noa:off` wins), last pacer tick, active events with hold/cancel and guest/pending counts.

Sends and actions reuse the existing routes: `/api/wa-send`, `/api/human`, `/api/media-dl`, `/api/pause`, `/api/pacer`, `/api/daily-run`, `/api/event-flag`, `/api/block-phone`, `/api/brain-toggle`, `/api/ipn-replay`.

Change log: `CHANGE_ROUTES` now also covers pacer, daily-run (real only), event-flag (writes only), block-phone (writes only, masked phone), ipn-replay (successful replays). New kind `control` ("שליטה ידנית") in worker/changes.js and the change-log screen.

## Screens (all lazy: assets/ops/lazy/, CSS assets/ops/p4a.css injected by them)
- הודעות `g m` (lazy/messaging.js, replaces screens/messaging.js): number cards + day picker + tabs הכל / נכשלו / תשובות, one row per message, click to expand (full text, reply, template, reason, status history, link to the conversation).
- אינבוקס `g i` (lazy/inbox.js): list + thread + composer. Free text inside the 24 h window, template chooser outside it. Every send opens a typed confirm with the word `שלח` (recipient, number and text shown). Clients/leads: no send 21:00–09:00. Per-chat switch "נועה עונה / אדם בשיחה" (turning Noa back on needs the word `נועה`). Media download through /api/media-dl. Links to the lead/client card.
- שליטה `g x` (lazy/control.js): pause/resume, pacer now, daily run dry/real, event hold/unhold/cancel/uncancel with an event picker, block/unblock/check phone, Noa AI on/off, IPN replay. Each one shows its blast radius and needs a typed word (dry run excepted).
- Phone: thread replaces the list with a back button; both screens are in the "עוד" sheet.
