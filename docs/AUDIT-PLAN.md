# יומן ביקורת מלא · החלטות ריצארד 22/10/2026

מטרה: תיעוד משפטי של כל מה שקורה בעסק (לקוחות, אורחים, וורקר, מטא, שיחות, תשלומים, סלאק, אדמין), עם ID וחותמת זמן שרת לכל רשומה, ניתן לייצוא, מופיע בלוג החי, באקסל הראשי, ובמייל שבועי.

## עקרונות
- מודול נפרד `worker/audit.js`, לא בתוך index.js. כל חלק עם תיאור.
- רשומה אחת לכל דבר: `{ id, at, ts, kind, area, action, ok, review, token, phone, ip, country, ua, detail, data, hash }`.
- `hash` = sha256 של תוכן הרשומה (ללא hash). בסוף כל יום: שורש (merkle) של כל רשומות היום נשמר ב-KV ונשלח לסלאק = עוגן חיצוני. ייצוא מאמת כל רשומה מול ה-hash שלה ומול השורש היומי.
- שימור: 400 יום ב-KV (`stream:<יום>:<ms>:<rand>`, אותו מפתח שהלוג החי כבר קורא). הקלטות שיחה: `rec:<call_id>` ב-KV, 400 יום.

## סוגי רשומות (kind) והסבר שיופיע במקרא
| kind | מה זה |
|---|---|
| client | פעולה של לקוח בלוח (כולל כל פתיחה/צפייה), עם IP ודפדפן |
| guest | אורח ענה / נרשם מהקישור / סומן |
| wa_out | הודעת וואטסאפ שיצאה (תבנית/חופשית), למי, איזה מספר שלח |
| wa_status | מטא דיווחה: נמסר / נקרא / נכשל (+קוד שגיאה) |
| wa_in | הודעה נכנסת מאורח/לקוח/ליד |
| call | שיחה של שיר/נועה: תוצאה, תמלול מלא, קישור להקלטה |
| pay | תשלום/חשבונית (Grow IPN, שדרוגים) |
| meta | אישורי תבניות, איכות מספר, מגבלות, אימות עסק |
| cron | ריצה של הוורקר: איזה job, מה בדק, מה עשה, כמה זמן |
| admin | פעולה של ריצארד/שלו/Claude דרך ה-API |
| slack | הודעה שנשלחה לסלאק |
| event | היומן הישן (logEvent) |
| system | פריסות גרסה, שגיאות לא צפויות |
