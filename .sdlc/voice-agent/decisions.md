# החלטות ריצ'רד · סוכן החיוג (29.08.2026)

נמסרו בצ'אט אחרי דף ההמלצה. אלה קובעות את ה-spec.

1. **קול ואישיות:** סוכנת, שם **שיר**. (בחירת הקול הספציפי — בדמו.)
2. **גילוי נאות:** פתיחה בסגנון "היי, שיר מאישורי הגעה". לא מתנדבת לספר
   שהיא אוטומטית — אבל אם שואלים, עונה בכנות שכן. (משפטית זה עומד:
   ההצגה בשם בעלי האירוע + נתיב אנושי + תמלילים נשמרים; אין עדיין חובת
   גילוי גורפת בחוק, והכנות-כששואלים סוגרת את הסיכון המעשי.)
3. **תא קולי:** ניתוק שקט. הניסיון לא נספר (לא ענה ≠ ניסיון שרוף כשזה
   תא קולי — נספר רק צלצול בלי מענה אמיתי? לא: תא קולי = ניתוק ולא
   נספר, dial_no_answer = נספר כ"לא ענה").
4. **מספר:** ריצ'רד רוצה מספר אחד גם לתפוצת הוואטסאפ וגם לשיחות של שיר.
   אושר שזה אפשרי ומומלץ — בתנאי שהמספר VoIP (SIP), לא SIM פיזי.
   **פתוח:** המספר הקיים שלו — SIM או וירטואלי? (אם SIM: ניוד ל-Telnyx/
   DIDWW או קניית 055 וירטואלי חדש.) תקציב טרם אושר סופית.

## עדכון (בהמשך אותו ערב)
5. **מספר — הוחלט:** המספר הנוסף של ריצ'רד הוא SIM פיזי, עדיין בלי
   וואטסאפ. התוכנית: ניוד המספר לספק VoIP (Telnyx/DIDWW) → אחרי הניוד
   רישום ל-WhatsApp Business API (תפוצה) + חיבור SIP ל-Retell (שיר).
   מספר אחד לכל: הודעות, שיחות יוצאות, ושיחות חוזרות מנותבות לריצ'רד.
6. **תקציב:** ‎₪1.4 לשיחה ממוצעת אושר כסביר. דרישה נלווית: תיעוד עלות
   אמיתית לכל הודעה ולכל שיחה כדי לדעת עלות ממוצעת לאורח, עם/בלי שיחה.
